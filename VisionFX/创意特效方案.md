# Vision FX · 创意特效方案（v2）

> 本文档面向**创作者 / C 端用户**，聚焦于**新增识别能力**带来的全新体验形态。
> 所有效果均基于 MediaPipe Tasks Vision 已发布的本地模型，端侧运行，无需联网即可体验。

---

## 1. 项目现状速览

| 模块 | 模型 | 已有识别能力 | 已有表现 |
| --- | --- | --- | --- |
| Reality Curtain | GestureRecognizer | 捏合手势（拇指+食指） | Verlet 物理幕布 + 揭示隐藏媒体 |
| Lip FX | FaceLandmarker | jawOpen / smile / pucker / funnel / frown | 唇线、声波、旋涡、心形粒子、蒲公英吹散 |

**视觉路线**：深色高对比 AI 工具界面，紧凑面板，状态条形图，**"装上摄像头就能出片"** 的极简操作感。

下面所有创意都沿着这条路线：**打开摄像头 → 做动作 → 直接生成可分享画面**，每个效果都设计成可作为独立 tab 接入。

## 3. 详细方案（选最有卖点的 6 个展开）

### 3.1 Look At Me · 眼神光（最易出片）

**一句话卖点**：闭眼 2 秒再睁眼，瞳孔上会迸出一道光——专门治愈"眼睛没神"的视频创作者。

- **新增能力**：FaceLandmarker 已支持 478 点的虹膜精细定位，开启 `outputFaceBlendshapes` 后还能取 `eyeBlinkLeft/Right`、`eyeLookUp/Down/In/Out` 等表情系数。
- **识别逻辑**：监测眨眼（blink 上升沿 → 下降沿），延迟 100ms 触发；或监测瞳孔朝向突变（lookOut → lookIn）触发"被看见"特效。
- **视觉表现**：
  - 触发瞬间在虹膜位置发射一道十字光芒（Canvas 2D `shadowBlur` + `createRadialGradient` 叠加）。
  - 配合 6 条彩色放射光线，按 blendshape 比例决定颜色（瞳孔外扩=暖色，内收=冷色）。
  - 同步弹出小字"**✦ Caught you looking ✦**"或"**眨眨眼**"，用项目现有的 UI 风格。
- **传播钩子**：做完后右下角加 **"录制 / 截图 / 分享"** 按钮，C 端用户一键生成 GIF/MP4。
- **落地成本**：复用 `FaceLandmarker` 模型，无需下载新模型。⭐

### 3.2 Brow Story · 眉语（社交互动利器）

**一句话卖点**：挑眉、皱眉、挤眉弄眼——脸上直接浮现弹幕，闺蜜/情侣视频聊天专用。

- **识别能力**：blendshape `browInnerUp / browOuterUpLeft/Right / browDownLeft/Right`，可识别 5 种眉动作。
- **视觉表现**：
  - 头顶弹出漫画式"标签云"——挑眉→"**嗯？**"、皱眉→"**别惹我**"、同时挑两边→"**天呐**"、单边挑→"**你好骚啊**"。
  - 标签样式沿用项目深色霓虹色板：`#ff6b9d / #f6c85f / #6fd5ff / #7757c9`。
  - 标签支持自定义文案，用户可以输入自己的弹幕库。
- **C 端彩蛋**：长按表情超过 1 秒 → 解锁"隐藏弹幕"，例如挤眉触发彩虹屁连击。
- **落地成本**：复用现有模型。⭐

### 3.3 Hand Composer · 手势乐团（最有"舞台感"）

**一句话卖点**：捏合是钢琴，张掌是鼓掌，弹指是节拍器——把你的手变成一支乐队。

- **新增模型**：MediaPipe **HandLandmarker**（21 关键点 × 最多 2 手），模型文件 `hand_landmarker.task`，与现有 `gesture_recognizer.task` 同源路径。
- **识别逻辑**（基于关键点几何，不依赖分类器）：
  - **捏合**：拇指尖(4) 与食指尖(8) 距离 < 阈值 → 持续触发。
  - **弹指**：中指(12) 在 100ms 内相对拇指(4) 移动距离突变 → 单次触发。
  - **张掌**：5 指全部伸直且掌心法线接近屏幕法线 → 持续触发。
  - **摇滚**：食指+小指伸直，其余弯曲 → 持续触发。
- **视觉表现**：
  - 捏合 → 食指指尖发出彩色声波圆环 + 钢琴音（WebAudio API）。
  - 张掌 → 两手掌心分别生成两个粒子鼓面，碰撞时迸发火星。
  - 弹指 → 屏幕中央出现节拍标记，每 4 拍循环。
  - 摇滚 🤘 → 整个画面切到霓虹滤镜，背景霓虹灯滚动。
- **UI 升级**：右侧面板显示"当前识别到的手指数"和"演奏强度"，沿用 metric-list 风格。
- **落地成本**：⭐⭐。需要下载新模型 + 简单几何分类 + WebAudio。

### 3.4 Pose Mirror · 全身镜像（线下活动引流神器）

**一句话卖点**：用户站在屏幕前，自己的全身剪影会像幽灵一样"反向同步"——一边是原速，一边是镜像，像走进了一面魔法镜子。

- **新增模型**：**PoseLandmarker Lite**（33 个关键点，CPU 可跑），模型 `pose_landmarker_lite.task`。
- **识别逻辑**：33 个关键点 + 可见性得分（visibility），过滤掉缺失严重的点。
- **视觉表现**：
  - 屏幕一分为二，左半 = 摄像头实时镜像视频，右半 = 抽象"骨架幽灵"（用 Canvas 2D 连线 + 圆点）。
  - 骨架线条沿用项目霓虹色板，**低头时**自动变成"火柴人流泪"插画。
  - 抬起一只手 → 屏幕上飘出对应颜色的"波纹"。
- **可选升级**：接入现有的 **Reality Curtain** 物理——双手向外一推，幕布向两边裂开，露出背后的"另一个我"（用户上一次留下的录像）。
- **落地成本**：⭐⭐。

### 3.5 Body Tape · 体感彩带（创作者最强视频素材）

**一句话卖点**：跳舞时手腕、脚踝、肩膀会拖出彩虹色丝带，速度越快颜色越亮——直接产出"星轨"风格的慢动作视频。

- **新增模型**：PoseLandmarker Lite（同 3.4）。
- **识别逻辑**：取每帧关键点位置，加入"轨迹缓冲"（最近 N 帧位置列表，按速度衰减透明度）。
- **视觉表现**：
  - 8 条彩带分别绑定：双手腕、双肘、双肩、头、髋。
  - 彩带宽度随关节瞬时速度变化（慢=细线，快=粗光带）。
  - 颜色 HSL 沿关节 ID 分配，整套色板与项目一致。
  - 配合 **慢动作回放**——举起手 2 秒后，自动生成一段 0.25x 慢速回放，叠加"星轨"在画面上。
- **C 端吸引力**：导出 1080p MP4 + 自动配 BGM（用 WebAudio 节奏合成）。
- **落地成本**：⭐⭐。

### 3.6 AR Sticker Pack · 道具栏（最有"可玩性"）

**一句话卖点**：把手机/杯子/键盘放在镜头前，它头顶会冒出一朵云，云上写着物体名字——小孩子会玩一整天。

- **新增模型**：**ObjectDetector**（基于 EfficientDet-Lite，模型 `efficientdet_lite0.tflite`，80 类 COCO 物体）。
- **识别逻辑**：检测到物体 → 在物体中心点上方悬浮一个 sticker，sticker 内容随物体类别变化（人→"VIP"，猫→"🐱 喵"，杯子→"☕ 加糖？"，键盘→"💻 工作中"）。
- **视觉表现**：
  - sticker 用 Canvas 2D 绘制毛玻璃背景 + 描边 + 软阴影，整体霓虹风格。
  - 物体移动时 sticker 跟随；物体消失时 sticker 上飘渐隐。
  - 配合 **HandLandmarker**：用手去"戳"sticker 会触发彩纸喷射。
- **可扩展**：用户上传自定义图片，sticker 自动套用 `image-to-image` 风格滤镜（可选接入 LLM/SD 模型）。
- **落地成本**：⭐⭐⭐。需要 ObjectDetector 模型 + 与现有 UI 整合 + sticker 模板系统。

## 4. 一份"完整插件菜单"——新增的 4 个补位效果

### 4.1 Pose Portal · 跨时空剪影（沉浸感最强）

- Pose + Selfie Segmentation：真人被前景提取出剪影，剪影外是隐藏视频。伸手一拉，剪影像幕布一样被拉走——把现有 **Reality Curtain** 的物理能力拓展到"人"。
- ⭐⭐⭐

### 4.2 Hand Paint · 空中作画（最具个人风格）

- HandLandmarker 单指追踪：食指指尖 = 画笔，手掌张开 = 橡皮，画完按"完成"生成签名水印视频。
- ⭐⭐

### 4.3 Pose Beat · 节奏教练（健身 / 跳舞房）

- PoseLandmarker + 内置节拍：屏幕给出节奏谱（挥左手/抬右腿/转身），用户按节拍做对位置，画面爆"PERFECT! / GREAT! / GOOD"。
- ⭐⭐⭐

### 4.4 Pose Chain · 接力拍照（朋友群最爽）

- 多帧 PoseLandmarker 缓冲：检测到多个人轮流进入镜头，每人单独生成一段 3 秒定格，最终合成"接力视频"。
- ⭐⭐⭐

```
Week 1  ★ Look At Me + Brow Story（复用现有模型，1 天搞定）
```

每个新能力都可以独立 tab 接入，沿用现有的：
- **顶部 tab 切换**（侧边栏 `nav-button`）
- **启动摄像头 / 停止摄像头** 按钮
- **右侧效果 + 输入 + 输出** 三个分区
- **深色霓虹色板** 与 **条形图指标**

新增的 UI 元素统一加到 `styles.css` 里，保持"AI 工具界面"质感。

## 6. "杀手级"传播钩子（针对 C 端）

要让创作者主动分享，必须做三个东西：

1. **一键截图 / 录屏**：右下角固定悬浮 `<circle-camera>` 按钮，点击生成 MP4（MediaRecorder API）。
2. **水印 + Logo**：每个效果结束时弹出 "**Made with Vision FX**"，可定制品牌水印（线下活动定制友好）。
3. **预设模板**：每个效果有 3 个预设（"赛博朋克 / 糖果色 / 极简黑"），用户可一键切换，立刻有"大片感"。
